# AI News and Misinformation Analyzer

## 1. Project Overview

AI News and Misinformation Analyzer is a beginner-friendly B.Tech AIML project that accepts a news headline and claim, analyzes simple linguistic signals, assigns a verdict, and stores the result in Supabase PostgreSQL.

The MVP uses an explainable rule-based analyzer rather than an external AI API. This keeps the project free, easy to understand, and runnable without an API subscription.

**Important:** The analyzer does not prove whether a news story is factually true. It identifies signals that may indicate credibility or misinformation and recommends further fact-checking.

## 2. Problem Statement

Misinformation can spread quickly through social media and news platforms. Students need a simple tool that demonstrates how software can analyze text and highlight suspicious or credible language.

## 3. Objectives

- Accept news claims from a user.
- Analyze text using transparent rules.
- Produce a verdict and confidence score.
- Explain the signals behind the result.
- Store analysis history in PostgreSQL.
- Provide a responsive browser interface.
- Demonstrate a complete frontend, REST API, and database workflow.

## 4. Target Users

The MVP is designed for students, teachers, and general users who want an educational first-level screening tool.

No login is required in this MVP. This avoids adding unnecessary authentication complexity to a first-year project. Because there is no account system, the history is shared by users of the running application.

## 5. Features

- News headline and content form.
- Backend validation with Zod.
- Explainable text analysis.
- Three verdicts: Likely True, Likely False, Needs Review.
- Confidence score from 0 to 100.
- Explanation of detected signals.
- Persistent analysis history in Supabase PostgreSQL.
- Search/filter history in the browser.
- REST API.
- Health-check endpoint.
- Helmet security headers.
- Rate limiting.
- Responsive HTML/CSS/Vanilla JavaScript UI.

## 9. Supabase Setup

1. Create a Supabase account and create a new project.
2. Open the project dashboard.
3. Open **SQL Editor**.
4. Create a new SQL query.
5. Copy the complete contents of `database/schema.sql`.
6. Paste the SQL into the editor.
7. Run the query.
8. Open **Table Editor** and verify that `news_analyses` exists.

### Obtain server credentials

In the Supabase project dashboard, open the project's API settings and copy:

- Project URL
- Server-side service role key

Put these values only in `backend/.env`.

Never put the service-role key in `frontend/app.js`, `index.html`, GitHub, or screenshots.

## 10. Environment Variables

Create `backend/.env`:

```env
PORT=3000
NODE_ENV=development
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-server-only-service-role-key
```

Replace the two Supabase placeholders with your own values.

`.env.example` is a safe template. `.env` contains private credentials and is ignored by Git.

## 14. API Endpoints

### GET /api/health

Checks whether the server is running.

### GET /api/analyses?limit=50

Returns recent stored analyses.

### GET /api/analyses/:id

Returns one analysis by UUID.

### POST /api/analyses

Creates and analyzes a news claim.

Request:

```json
{
  "headline": "Example news headline",
  "content": "Example news claim with enough text for analysis."
}
```

Successful response:

```json
{
  "data": {
    "id": "uuid",
    "headline": "Example news headline",
    "content": "Example news claim with enough text for analysis.",
    "verdict": "Needs Review",
    "confidence_score": 50,
    "explanation": "No strong linguistic signal was detected. The claim needs external fact-checking.",
    "created_at": "timestamp"
  }
}
```

Input errors return HTTP 400. Unexpected server/database errors return HTTP 500 without exposing internal details.

## 15. How the Analyzer Works

The MVP is deliberately explainable.

1. The backend combines the headline and content.
2. It searches for sensational expressions such as "shocking", "miracle", "urgent", and similar wording.
3. It searches for credibility-related signals such as "study", "research", "official", "data", and "evidence".
4. The score starts at 50.
5. Sensational signals reduce the score.
6. Credibility signals increase the score.
7. Very short content receives a penalty.
8. The final score is converted to a verdict:
   - 70–100: Likely True
   - 36–69: Needs Review
   - 0–35: Likely False

This is a demonstration of text analysis, not a real-world fact-checking model.

## 17. Troubleshooting

### `SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY must be configured`

Check that `backend/.env` exists and contains both variables. Restart the server after changing `.env`.

### `relation "news_analyses" does not exist`

Run `database/schema.sql` in the Supabase SQL Editor.

### Port already in use

Change:

```env
PORT=3001
```

Then open `http://localhost:3001`.

### `npm is not recognized`

Install Node.js LTS and reopen VS Code.

### CORS errors

The supplied server enables CORS. When using the normal setup, open the application through `http://localhost:3000` rather than opening `index.html` directly with a `file://` URL.

### Git accidentally includes `.env`

Stop and remove the secret from Git tracking. If a real credential was pushed, rotate/revoke that credential immediately and remove the exposed secret from repository history.

## 19. Security

- Helmet adds common security headers.
- Rate limiting reduces repeated API abuse.
- Zod validates incoming request data.
- Supabase service-role credentials remain server-side.
- User-provided text is escaped before being inserted into the page.
- The API does not expose database stack traces.
- Database RLS is enabled.
- The backend is the trusted layer for database access.

## 20. Limitations

The MVP does not use a trained machine-learning model or external fact-checking database. It therefore cannot establish the truth of a claim.

Future improvements could include:

- Supabase Auth and individual user histories.
- A trained NLP/ML classification model.
- Source credibility scoring.
- Citation/source extraction.
- Admin review workflow.
- More advanced NLP features.
- Multilingual news analysis.
- Deployment using a Node-compatible hosting platform.
